## 仪式 · 旧去新来

在诡秘之主的世界里，战争与灵性同样残酷而神秘。

### Problem Description

某位隶属于隐秘组织的非凡者被派往一片象征**秩序崩塌**的建筑群，其可以被视作一个由 $n \times m$ 个格点组成的灵性矩阵，每个格点都蕴含着建筑的价值，如同灰雾之上闪烁的符号。

非凡者的任务是举行仪式：

一共需要执行 $k$ 次轰炸仪式，每一次仪式都选择当前尚存建筑中价值最高的一座作为 **祭品** ，炸弹降下后，该建筑所在的整行与整列都被抹除，象征性地被清洗，随后剩余的地块被重新组合，形成一个尺寸减少一行一列的矩阵。

例如，对矩阵：

```
5 6 7
3 9 8
2 1 4
```

一次仪式后，行列被清除并重新组合，结果为：

```
5 7
2 4
```

这就像非凡世界中的一次仪式净化：旧的秩序被抹去，新的结构重新形成。

### Input

第一行给出三个整数 $n,\ m,\ k$
$(2 \le n,\ m \le 1000,\ k<\min(n,m))$。

接下来的 $n$ 行，每行 $m$ 个整数表示建筑价值。

题目保证所有价值在 $\text{int}$ 范围内，且互不相同。

### Output

输出轰炸 $k$ 次后的最终矩阵，同一行数字以一个空格分隔。

注意：行首与行尾无多余符号。

### 样例输入 1

```
4 5 2
3 8 6 1 10
28 9 21 37 5
4 11 7 25 18
15 23 2 17 14
```

### 样例输出 1

```
3 6 10
4 7 18
```

## 代码

```c++
#if 1
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <vector>
#include <set>
#include <algorithm>
#include <utility>
using namespace std;
typedef pair<int, pair<int, int>> pii;
signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<vector<int>> building(n, vector<int>(m));
    vector<pii> bxy;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> building[i][j];
            bxy.push_back({ building[i][j],{i,j} });
        }
    }
    sort(bxy.begin(), bxy.end());
    set<int> has_boom_x;
    set<int> has_boom_y;
    int boom_times = 0;
    while (boom_times < k)
    {
        int x = bxy.back().second.first;
        int y = bxy.back().second.second;
        bxy.pop_back();
        if (has_boom_x.count(x) == 0 && has_boom_y.count(y) == 0)
        {
            boom_times++;
            has_boom_x.insert(x);
            has_boom_y.insert(y);
        }
    }
    vector<bool> exist_x(n, 1), exist_y(m, 1);
    for (auto x : has_boom_x) { exist_x[x] = 0; }
    for (auto y : has_boom_y) { exist_y[y] = 0; }
    vector<vector<int>> ans;
    for (int i = 0; i < n; i++)
    {
        if (exist_x[i] == 0) { continue; }
        vector<int>temp;
        for (int j = 0; j < m; j++)
        {
            if (exist_y[j] == 0) { continue; }
            temp.push_back(building[i][j]);
        }
        ans.push_back(temp);        
    }

    for (int i = 0; i < ans.size(); i++)
    {
        for (int j = 0; j < ans[0].size(); j++)
        {
            cout << ans[i][j];
            if (j < ans[0].size() - 1) { cout << ' '; }
            
        }
        if (i < ans.size() - 1) { cout << '\n'; }
    }
    return 0;
}
#endif
```
