## H. 非凡者评级

**题目类型**：传统题 
**时间限制**：1000ms 
**内存限制**：256MiB

---

### 题目背景

> 序列越高,位格越尊,力量越强,这是非凡世界最基础的秩序。

### 题目描述

塔罗会的执事们需要对贝克兰德城内登记在册的 $n$ 位非凡者进行**非凡能力评级**,以此作为分配任务的依据。

执事们已为每位非凡者核定了最终的「非凡度评分」,其中第 $i$ 位非凡者的评分记为 $s_i$。

每位非凡者的评分依据其 $m$ 项核心**非凡属性**综合判定,第 $i$ 位非凡者的第 $j$ 项属性值记为 $p_{i,j}$,每项属性的取值范围为 $0$ 到 $k$（包含两端,$k$ 由对应的非凡属性上限决定）。

第 $i$ 位非凡者的**总能力值**是其所有 $m$ 项属性的总和,记为：
$$v_i = \sum_{j=1}^{m} p_{i,j}$$

为了保证评级的合理性,执事们提出核心要求：

对于任意两位非凡者 $1 \le i, j \le n$：

- **若 $s_i > s_j$（即 $i$ 的非凡度更高）,则必须满足 $v_i > v_j$（即 $i$ 的总能力值更大）**。
- **若 $s_i = s_j$,那么总能力值谁大谁小都可以,亦可以相等,没有限制**。

遗憾的是,**部分非凡者的非凡属性数据被「迷雾干扰」,因此缺失**。

作为塔罗会的助理,你需要填充这些缺失的属性值,确保上述评级规则严格成立。

### 输入格式

第一行输入一个整数 $T$ ($1 \le T \le 1 \times 10^5$) 表示数据组数,对于每组数据：

第一行输入三个整数 $n$、$m$ 和 $k$（$2 \le n \le 4 \times 10^5$,$1 \le m \le 4 \times 10^5$,$n \times m \le 4 \times 10^5$,$1 \le k \le 10^9$）,分别表示待评级的非凡者数量、每位非凡者的非凡属性数、每种非凡属性的取值上限。

接下来 $n$ 行,第 $i$ 行首先输入一个整数 $s_i$（$1 \le s_i \le 10^9$）表示第 $i$ 位非凡者的非凡度评分,随后输入 $m$ 个整数 $p_{i,1}, p_{i,2}, \cdot\cdot\cdot, p_{i,m}$（$-1 \le p_{i,j} \le k$）,含义如下：

- 若 $p_{i,j} = -1$,表示该非凡者的第 $j$ 项属性数据缺失,你需要填充一个合法值。
- 若 $p_{i,j} \ge 0$,表示该属性值已确认,不可修改。

**保证所有测试数据中,$n \times m$ 的总和不超过 $4 \times 10^5$。**

### 输出格式

对于每组数据：

- 若可以填充所有缺失属性值并满足评级规则,首先输出一行 `Yes`。
  - 随后输出 $n$ 行,第 $i$ 行包含 $m$ 个由单个空格分隔的整数 $q_{i,1}, q_{i,2}, \cdot\cdot\cdot, q_{i,m}$（$0 \le q_{i,j} \le k$）,$q_{i,j}$ 为填充后的第 $i$ 位非凡者的 $m$ 项非凡属性值。
  - 若原 $p_{i,j} \ge 0$,则 $q_{i,j} = p_{i,j}$。
  - 若原 $p_{i,j} = -1$,则为你填充的合法值。
- 若存在多种合法填充方案,输出任意一种即可。
- 若无法满足评级规则,仅需输出一行 `No`。

### 提示

对于第二组样例数据,即使我们将唯一的 $-1$ 填入最大的可能值 $10$,第一位非凡者的总能力值也只有 $15$,无法大于第二位非凡者的总能力值 $30$。

## 代码

```c++
#if 1
#include<bits/stdc++.h>
#define int long long
using namespace std;
typedef pair<int,vector<int>> pii;
signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    int T;cin>>T;
    for (int times = 0; times < T; times++)
    {
        int n, m, k; cin >> n >> m >> k;
        vector<pii> arr;
        for (int i = 0; i < n; i++)
        {
            pii temp;
            temp.second.push_back(i);//数组中第一个数为索引
            int s;
            cin >> s;
            temp.first = s;
            for (int j = 0; j < m; j++)
            {
                int p; cin >> p;
                temp.second.push_back(p);
            }
            arr.push_back(temp);
        }
        sort(arr.begin(), arr.end());
        int max_s = -1;
        int new_sum = -1;
        int past_sum = -1;
        vector<vector<int>> ans(n);
        for (int i = 0; i < n; i++)
        {            
            int sum = 0;
            int empty = 0;
            vector<int> index_neg_1;
            for (int j = 1; j <= m; j++)
            {
                if (arr[i].second[j] == -1) { empty++; index_neg_1.push_back(j); }
                else { sum += arr[i].second[j]; }
            }
            if (sum > past_sum) 
            {
                new_sum = max(new_sum, sum);
                for (int j = 0; j < index_neg_1.size(); j++)
                {
                    arr[i].second[index_neg_1[j]] = 0;
                }
            }
            else if (sum + k * empty <= past_sum)
            {
                goto flag;
            }
            else
            {
                new_sum = max(new_sum, past_sum + 1);
                for (int j = 0; j < index_neg_1.size(); j++)
                {
                    int temp_val = min(past_sum + 1 - sum, k);
                    arr[i].second[index_neg_1[j]] = temp_val;
                    sum += temp_val;
                }
            }

            if (arr[i].first > max_s)
            {
                max_s = arr[i].first;
                past_sum = new_sum;
            }
            
        }
        for (int i = 0; i < n; i++)
        {
            ans[arr[i].second[0]] = arr[i].second;
        }
        cout << "Yes" << endl;
        for (int i = 0; i < n; i++)
        {
            for (int j = 1; j <= m; j++)
            {
                cout << ans[i][j];
                if (j != m) { cout << ' '; }
            }
            if(i != n) { cout << endl; }
        }
        if (times != T) { cout << endl; }
        continue;
    flag:
        cout << "No";
        if (times != T) { cout << endl; }
    }
    return 0;
}
#endif
```
