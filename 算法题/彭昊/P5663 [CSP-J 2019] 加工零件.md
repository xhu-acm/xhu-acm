#### 思路

我首先看了看题目中的示例输出，很容易发现1号工人提供原料的必要不充分条件是：生产L号零件的工人与1号工人的最小距离小于或等于L 。那充要条件呢？找规律可以发现（猜测），充要条件是：a号工人与1号工人的与L奇偶性相同的最小距离小于或等于L 。

#### 题解

要求a号工人与1号工人的与L奇偶性相同的最小距离，我首先想到的是图论BFS 。因为要查询指定工人的每个传送带，所以使用邻接法。定义vector<unordered_set<int>> worker[i]为所有与第i号工人相邻的工人组成的集合，far_2_1[i][0]表示从1到i的偶数最短距离，far_2_1[i][1]表示从1到i的奇数最短距离，然后使用两个队列分别存储步数和工人，实现BFS。



#### 代码

```c++
#if 1
#include<bits/stdc++.h>
#include<unordered_set>
//#define int long long
using namespace std;
const int inf = 2100000000;
int n, m, q;
vector<unordered_set<int>> worker;
vector<vector<int>>far_2_1;//表示某个工人与一号工人的距离

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    cin >> n >> m >> q;
    worker.resize(n + 1);
    far_2_1.resize(n + 1, {inf,inf});
    for (int i = 0; i < m; i++)
    {
        int a, b; cin >> a >> b;
        worker[a].insert(b);
        worker[b].insert(a);
    }
    queue<int> qu;
    queue<int> step;
    step.push(0);
    qu.push(1);
    while (!qu.empty())
    {
        int i = qu.front();
        int st = step.front() + 1;
        qu.pop();
        step.pop();
        bool is_2 = st % 2;
        for (auto j : worker[i])
        {
            if (far_2_1[j][is_2] ==inf)
            {
                far_2_1[j][is_2] = st;
                qu.push(j);
                step.push(st);
            }
        }
    }
    for (int i = 0; i < q; i++)
    {
        int a, l;
        cin >> a >> l;
        if (far_2_1[a][l % 2] > l)
        {
            cout << "No";
        }
        else
        {
            cout << "Yes";
        }
        cout << endl;
    }


    system("pause");
    return 0;
}
#endif
```

## 题目重述

给定无向图 $G=(V,E)$，其中 $|V|=n$，$|E|=m$。定义生产过程：若工人 $a$ 想生产一个 $L\,(L>1)$ 阶段的零件，则所有与 $a$ 直接相连的工人都需要生产一个 $L-1$ 阶段的零件；若 $L=1$，则所有与 $a$ 直接相连的工人都需要为 $a$ 提供一个原材料。

对于查询 $(a,L)$，判断 $1$ 号工人是否需要提供原材料。

## 符号定义

- 令 $P(v,k)$ 表示：当 $a$ 想生产 $L$ 阶段零件时，工人 $v$ 是否需要生产一个 $k$ 阶段的零件（$1 \leq k \leq L$）。
- 特别地，当 $k=1$ 时，若 $P(u,1)$ 为真，则所有与 $u$ 相邻的工人需要提供原材料。

## 递推关系

根据题意：

1. $P(a,L)$ 为真。
2. 对于 $k < L$，$P(v,k)$ 为真当且仅当存在 $u \in N(v)$（$u$ 是 $v$ 的邻居）使得 $P(u,k+1)$ 为真。

## 关键引理与证明

**引理1**：$P(v,k)$ 为真当且仅当存在一条从 $a$ 到 $v$ 的长度为 $L-k$ 的路径。

**证明**：对 $k$ 从 $L$ 向下归纳。

- **基础**：$k=L$ 时，$P(v,L)$ 为真当且仅当 $v=a$，对应从 $a$ 到 $a$ 的长度为 $0$ 的路径，成立。
- **归纳假设**：假设对 $k+1$ 成立，即 $P(u,k+1)$ 为真当且仅当存在一条从 $a$ 到 $u$ 的长度为 $L-(k+1)$ 的路径。
- **归纳步骤**：
  - 若 $P(v,k)$ 为真，由定义存在邻居 $u$ 使 $P(u,k+1)$ 为真。由归纳假设，存在从 $a$ 到 $u$ 的长度为 $L-k-1$ 的路径，加上边 $(u,v)$ 即得从 $a$ 到 $v$ 的长度为 $L-k$ 的路径。
  - 反之，若存在从 $a$ 到 $v$ 的长度为 $L-k$ 的路径，设路径上 $v$ 的前驱为 $u$，则从 $a$ 到 $u$ 的长度为 $L-k-1$。由归纳假设 $P(u,k+1)$ 为真，且 $v$ 是 $u$ 的邻居，故 $P(v,k)$ 为真。

**推论**：$P(u,1)$ 为真当且仅当存在一条从 $a$ 到 $u$ 的长度为 $L-1$ 的路径。

## 原材料需求条件

$1$ 号工人需要提供原材料当且仅当存在某个邻居 $u$ 使得 $P(u,1)$ 为真，即存在邻居 $u$ 使得存在一条从 $a$ 到 $u$ 的长度为 $L-1$ 的路径。这等价于存在一条从 $a$ 到 $1$ 的长度为 $L$ 的路径（在从 $a$ 到 $u$ 的路径后添加边 $(u,1)$）。

因此：
$$
\text{1号需要提供原材料} \iff \exists \text{一条从 } a \text{ 到 } 1 \text{ 的长度为 } L \text{ 的路径}.
$$

## 路径存在性判定

设 $d_{\min}(a,1)$ 为从 $a$ 到 $1$ 的最短路径长度。由于图是无向的，$d_{\min}(a,1) = d_{\min}(1,a)$。

**引理2**：存在一条从 $a$ 到 $1$ 的长度为 $L$ 的路径当且仅当 $d_{\min}(1,a)$ 与 $L$ 同奇偶性且 $d_{\min}(1,a) \leq L$。

**证明**：

- 必要性：若存在长度为 $L$ 的路径，则最短路径长度 $d \leq L$，且路径长度奇偶性相同（因为最短路径与 $L$ 同奇偶性）。
- 充分性：若 $d \leq L$ 且 $d \equiv L \pmod{2}$，则可在最短路径上通过“往返走”任意偶数步（如在某条边上重复行走）将路径延长至长度 $L$，从而得到一条长度为 $L$ 的路径。

## 最终结论

综合上述分析，得到判定条件：

$$
\text{输出 Yes} \iff \exists \text{奇偶性为 } L \bmod 2 \text{ 的从 } 1 \text{ 到 } a \text{ 的路径，且其最短长度 } \leq L.
$$
