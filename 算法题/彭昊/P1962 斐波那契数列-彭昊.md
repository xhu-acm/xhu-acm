[P1962 斐波那契数列 - 洛谷](https://www.luogu.com.cn/problem/P1962)（模板题）

#### 思路

由于题目的数据范围达到了$2^{63}$，循环或者递归都不行，看了题解后才知道可以将线性代数和快速幂结合起来，即矩阵加速。

#### 题解

如果相邻两项$f_{i-1}$与$f_{i}$组成向量$\begin{bmatrix} f_{i-1} \\ f_{i} \end{bmatrix}$,那么在线性变换$\begin{bmatrix} 0 & 1 \\ 1 & 1 \end{bmatrix} $下可以得到$\begin{bmatrix} f_{i} \\ f_{i-1}+f_{i} \end{bmatrix}$即$\begin{bmatrix} f_{i} \\ f_{i+1} \end{bmatrix}$。

所以初始矩阵$\begin{bmatrix} 1 \\ 1 \end{bmatrix}$经过$n-2$次线性变换就可以得到$\begin{bmatrix} f_{n-1} \\ f_{n} \end{bmatrix}$。

而矩阵乘法满足分配律，所以可以先利用快速幂的方法求出${\begin{bmatrix} 0 & 1 \\ 1 & 1 \end{bmatrix}}^{n-2} $，然后再利用${\begin{bmatrix} 0 & 1 \\ 1 & 1 \end{bmatrix}}^{n-2}\begin{bmatrix} 1 \\ 1 \end{bmatrix}=\begin{bmatrix} f_{n-1} \\ f_{n} \end{bmatrix}$在$O(\log n)$的时间复杂度下求得$f_n$。

#### 代码

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int mod = 1000000000 + 7;
signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    int n; cin >> n;
    if (n == 1) { cout << 1 << endl; return 0; }
    if (n == 2) { cout << 1 << endl; return 0; }
    int t = n - 2;
    int ve[4] = { 0,1,1,1 };
    int fbnq[2] = { 1,1 };
    while (t)
    {
        if (t % 2 == 1)
        {
            int temp1[2];
            temp1[0] = (ve[0] * fbnq[0] + ve[2] * fbnq[1]) % mod;
            temp1[1] = (ve[1] * fbnq[0] + ve[3] * fbnq[1]) % mod;
            fbnq[0] = temp1[0]; fbnq[1] = temp1[1];
        }
        int temp2[4];
        temp2[0] = (ve[0] * ve[0] % mod + ve[2] * ve[1] % mod) % mod;
        temp2[1] = (ve[1] * ve[0] % mod + ve[3] * ve[1] % mod) % mod;
        temp2[2] = (ve[0] * ve[2] % mod + ve[2] * ve[3] % mod) % mod;
        temp2[3] = (ve[1] * ve[2] % mod + ve[3] * ve[3] % mod) % mod;

        ve[0] = temp2[0]; ve[1] = temp2[1];
        ve[2] = temp2[2]; ve[3] = temp2[3];

        t /= 2;
    }
    cout << fbnq[1] << endl;

    system("pause");
    return 0;
}
```
